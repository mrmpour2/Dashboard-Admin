# Feature Data

داده‌های نمایشی هر قابلیت در کنار همان Feature نگهداری می‌شوند تا ساختار پروژه به معماری واقعی نزدیک‌تر باشد.

- `Home/data.js` — آمار داشبورد، فروش هفتگی و فعالیت‌های اخیر
- `Products/data.js` — فهرست محصولات، موجودی، فروش و امتیاز
- `Users/data.js` — کاربران، نقش، وضعیت، سفارش‌ها و ارزش خرید
- `Tickets/data.js` — تیکت‌ها و پیام‌های نمونه هر تیکت
- `Comments/data.js` — نظرات، امتیاز، وضعیت بررسی و متن نظر

این اطلاعات کاملاً Fake هستند و فقط برای توسعه UI، تست فیلتر/مرتب‌سازی، نمایش حالت‌های مختلف و شبیه‌سازی تجربه یک پنل مدیریتی استفاده می‌شوند.
