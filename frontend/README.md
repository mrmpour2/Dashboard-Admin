# 🚀 React Dashboard

A modern and scalable Admin Dashboard built with React, Vite, Tailwind CSS, and modern frontend tools.

![Dashboard Preview](./public/preview.png)

---

## ✨ Features

- 🔐 Authentication
- 👤 User Management
- 📊 Dashboard Analytics
- 🌙 Dark / Light Mode
- 📱 Responsive Design
- ⚡ Fast Performance
- 🔎 Search & Filtering
- 📄 Pagination
- 📦 Reusable Components
- 🛡 Protected Routes
- 🔄 Data Fetching
- 🌍 RTL Support
- 🎨 Clean UI

---

## 🛠 Tech Stack

| Technology              | Description      |
| ----------------------- | ---------------- |
| React 19                | UI Library       |
| Vite                    | Build Tool       |
| React Router            | Routing          |
| Tailwind CSS            | Styling          |
| Redux Toolkit / Zustand | State Management |
| TanStack Query          | Server State     |
| Axios                   | API Requests     |
| React Hook Form         | Forms            |
| Zod                     | Validation       |
| React Hot Toast         | Notifications    |
| Lucide React            | Icons            |
| Framer Motion           | Animations       |
| ESLint                  | Linting          |
| Prettier                | Code Formatting  |

## 🚀 Installation

```bash
git clone https://github.com/username/dashboard.git

cd dashboard

npm install

npm run dev
```
